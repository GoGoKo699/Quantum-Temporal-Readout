# Scientific account

The experiment measures an unknown Pauli expectation by passing a source probe and known references through the same destructive detector. The reference records can reveal a relative error that a single report cannot resolve.

1. [Detector and temporal order](model.md) gives the causal measurement model, the additive error identity and the example with blind proper marginals.
2. [Calibration and inference](calibration.md) gives a drift-valid confidence certificate and the simultaneous product-Pauli result.
3. [The cost of learning a decoder](context-cost.md) proves the matching acquisition law for an unstructured uniform-context family.
4. [Phase drift and control](physical-model.md) connects the abstract detector to a thresholded phase model and states how control errors enter the confidence bound.

For scientific context see [Related work](../references/RELATED_WORK.md). For worked calculations and source prerequisites start with [Learning](../learning/README.md).
